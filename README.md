## ⚙️ Setup

1. **Clone the repository**  
   ```bash
   git clone https://github.com/username/project-name.git
   ```
2. **Install dependencies**  
   ```bash
   npm install
   ```
3. **Run the application**  
   ```bash
   npm start
   ```
